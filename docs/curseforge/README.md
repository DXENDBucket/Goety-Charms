# CurseForge listing files

- `icon.png`: square transparent PNG, author bucket series.
- `summary.txt`: English project summary.
- `description.md`: English Markdown description.
- `summary.zh-CN.txt` / `description.zh-CN.md`: Chinese alternatives.

Copy the summary and Markdown description into the corresponding CurseForge fields. This directory prepares assets only; it does not create a project or upload anything.
