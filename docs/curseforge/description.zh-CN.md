# 诡厄符咒 · Goety Charms

在祭坛准备，将仪式随身携带。

**诡厄符咒**可以把受支持的 Goety 仪式封存为一次性符咒。提前完成材料与环境准备，之后在需要的地方长按释放。

## 四类符咒

| 类型 | 用途 |
| --- | --- |
| **召唤符咒** | 在选定位置释放原生仪式的召唤结果，保留生物归属、变体、装备、存续规则和适用的召唤上限。 |
| **转化符咒** | 对准符合条件的生物，执行原生转化；物品说明会列出可用目标。 |
| **传送符咒** | 返回制作时投入的指路石记录的目的地，沿用原生同维度传送逻辑。 |
| **定位符咒** | 从使用地点寻找指定结构，获得 Goety 原生探索地图。 |

符咒不会把原本敌对的召唤结果变成友军。

## 制作与使用

工作台正中放纸，上下左右各放一颗下界石英，四角留空，合成 **空白符咒 ×4**。

1. 按原仪式要求搭建黑暗祭坛及环境。
2. 将原激活物和所有辅材放在周围基座上。
3. 手持空白符咒右键祭坛。研究、灵魂费用、持续时间、环境与献祭条件沿用来源配方。
4. 如果材料匹配多个仪式，潜行右键切换，普通右键确认。
5. 完成后取出符咒，长按右键一秒释放。

转化生物只需在释放时提供。制作传送符咒时需要已绑定同维度坐标的指路石，实际坐标会随符咒保存；定位符咒在使用时才搜索结构。

生存模式成功释放消耗一枚，目标不符或释放失败时保留；创造模式不消耗。仪式的灵魂费用已在制作时支付，释放时不重复收取。成品可以交给没有完成相应研究的人使用。

定位需要等待，请将选中的符咒留在物品栏；成功交付地图后才消耗。背包已满时，地图会掉落在身边。

## 配方与兼容

受支持的仪式会自动生成真正的封存配方，显示在 **Goety 原生 JEI 仪式页面**。附属或数据包若沿用受支持的原生召唤、转化、传送和定位执行类，也可以自动接入；自定义执行逻辑可能需要专门适配。

目前不支持把普通制造、附魔等所有仪式都封进符咒。创造栏里没有封存数据的条目只是样本，需要实际制作或用管理指令获取成品。

## 可选 Ars 联动

同时安装 **Goety & Nouveau 0.1.13+** 及其前置后，可以制作效果魔符 **启符**。例如 **弹射物 → 启符**，使用 Ars 命中的位置或生物释放随身携带的召唤／转化符咒。

查找顺序为：**副手 → 快捷栏从左到右 → 背包逐行从左到右、从上到下**。选中后失败不会继续尝试下一枚，也不会重复收取仪式灵魂费用。启符暂不使用传送和定位符咒。

通过原生抄写台，使用 **空白符咒 + 魔源宝石** 制作魔符。Goety Charms 本体不要求安装 Ars Nouveau、Ars Conflux 或 Goety & Nouveau。

## 配置与前置

常规配置提供总开关、长按时长和来源仪式排除列表。修改配方排除后需要重载数据；已删除或禁用的仪式无法通过旧符咒释放。

支持 **Minecraft 1.21.1 / NeoForge** 与 **1.20.1 / Forge**，客户端和服务端均需安装 Goety 及其前置。
